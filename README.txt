RIFT DEFENSE - web app package
==============================
Files: index.html, sw.js, manifest.webmanifest, icon-*.png, .nojekyll
(Upload ALL of them, including the hidden ".nojekyll" if your computer shows it.)

Put on GitHub Pages (free):
 1. github.com -> New repository -> name it rift-defense -> Public -> Create.
 2. Click "uploading an existing file", drag in every file from this folder, Commit.
 3. Settings -> Pages -> Source: "Deploy from a branch", Branch: main, folder: / (root) -> Save.
 4. After ~1 minute the game is live at https://jhunt2323.github.io/rift-defense/

iPhone: open that link in Safari -> Share -> Add to Home Screen. Plays full-screen, works offline.
PC: open the link in Chrome/Edge -> install icon in the address bar (optional), or just play in the tab.

Updating later: upload the new index.html and change VERSION in sw.js (e.g. rd-v2) so phones refresh.
